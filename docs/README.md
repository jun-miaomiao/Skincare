# 法務頁（GitHub Pages）

本目錄由 GitHub Pages 發佈：

1. 打開 repo **Settings → Pages**
2. **Source**：Deploy from a branch
3. Branch：`main`，資料夾：`/docs`
4. Save

約 1～2 分鐘後可開啟：

- https://jun-miaomiao.github.io/Skincare/privacy.html
- https://jun-miaomiao.github.io/Skincare/terms.html
